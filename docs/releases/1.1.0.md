# Pulse 1.1.0

Release date: 2026-10-31. License: MIT. Tag: `v1.1.0`.

Pulse's first public release brings projects, notes, todos, reminders, an inbox
and long-term agent memory into one self-hosted application. The core runs with
Python's standard library and SQLite, with a browser UI, CLI and 43 MCP tools.

## Included

- Five-column project boards, optional GitHub issue sync, Markdown notes and search.
- Todos, repeating reminders, optional Telegram delivery and private items hidden from agents.
- Built-in memory, optional external memory and a read-only Obsidian notes mirror.
- Hardened authentication, privacy propagation, safe notification links, durable
  delivery retries and validated backups.
- An opt-in agent-network preview: scoped identities and grants, offline requests,
  approved file exchange and device workers that invoke installed agent runtimes.

## Install and upgrade

Follow the [quick start](../../README.md#quick-start) for a fresh installation.
Python 3.10+ needs SQLite FTS5 and an IANA timezone database. No Python packages,
Node build or Docker are required by the core. The optional artifact store uses
separately installed Copyparty; task execution requires the chosen agent runtime
and its own authentication. Those components retain their respective licenses.

Before upgrading an existing installation, privately back up its database,
configuration and any network artifacts/credentials. Rehearse using disposable
data and keep the matching old code for rollback. Migrations 5–7 add privacy
provenance, durable delivery and agent-network state. Ambiguous legacy history
becomes owner-only; existing client tokens are preserved. See
[release checks](../release-checks.md) and [deployment](../deployment.md).

## Known limits

- Linux is the qualified platform; Windows and macOS are unqualified. The UI is
  browser-based; native mobile workers are not included.
- Agent networking and task workers are an opt-in preview. An offline device can
  leave a request queued until reconnect or expiry. Queued does not mean executed.
- Workers launch fresh sessions and can exercise the configured runtime's local
  privileges. Enable only trusted requesters and deliberately selected folders.
  Adapter tests do not establish universal client/runtime compatibility.
- Transfers are buffered and limited to 32 MiB per file, with a default 256 MiB
  registered-artifact quota. This is not a shared editable filesystem.
- Telegram delivery is bounded at-least-once: a crash after sending can produce
  a duplicate. An in-flight message cannot be recalled.
- Backup helpers do not create an independent off-host backup automatically.
- The release publishes source and installation instructions. Deployment receipts
  describe prior dated installations, not a managed service or current device availability.
