# Pulse 1.2.0

Release date: 2026-11-05. License: MIT. Tag: `v1.2.0`.

Pulse 1.2.0 adds native Windows and macOS support, a redesigned Agents directory,
an owner-enabled shared workspace for enrolled agents, and a Pulse brand refresh.
The core still uses Python's standard library and SQLite. Linux, Windows and
macOS are now qualified on their hosted CI images; see the scope below.

## Included

- Native Windows and macOS support with a manual qualification matrix on Python 3.10,
  3.12 and 3.13, including real Copyparty transfers on each OS.
- Windows file locks, guarded file handles, task job objects, and path/link
  protections. Fixes for Windows backup flushing, UTF-8 MCP/CLI/note handling and
  process-group cleanup on macOS.
- Redesigned Agents view: named devices (PC/VPS/Cloud), labelled presence and a
  readable task-session inbox.
- Owner-enabled shared workspace: 1 GiB capacity, 24-hour expiry, verified uploads and
  downloads, CLI/MCP tools, and temporary files excluded from backups.
- Light, dark and system appearance themes, the Pulse brand identity, and a
  Buy Me a Coffee support link and logo.

## Install and upgrade

Follow the [quick start](../../README.md#quick-start) for a fresh installation, or
the [native platform guide](../platforms.md) for Windows and macOS.

Before upgrading an existing installation, back up its database, configuration and
network artifacts privately, record the current commit and keep the 1.1.0 code for
rollback. See [release checks](../release-checks.md).

Migration 8 is new in this release. It creates the `network_devices` table, backfills
it from existing agent records and adds an audit index. Existing data stays in place.
Migrations 5–7 are unchanged from 1.1.0.

## Known limits

- Windows is qualified on Windows Server 2025, not a physical Windows 11 PC.
- macOS is qualified on Apple silicon only. Intel Macs and older macOS releases are
  not covered.
- Installed agent runtimes, long-running background services (Windows Task Scheduler,
  macOS LaunchAgent, systemd), sleeping laptops and network filesystems are not
  qualified.
- Agent networking and task workers remain an opt-in preview. Queued requests are not
  execution; workers launch fresh sessions with the configured runtime's local
  privileges.
- Shared-workspace files are limited to 32 MiB each, and each file is buffered in
  memory. Total capacity is owner-configured, initially 1 GiB.
